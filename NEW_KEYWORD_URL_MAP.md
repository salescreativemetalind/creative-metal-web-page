## Clustering Notes

Each cluster maps close variants onto ONE owner so the single-primary-URL rule holds while individual commercial intents stay distinct.

**1. Mild Steel** — Form-specific terms each own their dedicated page (plate/angle/channel/beam/flat bar). Generic head terms (`mild steel supplier`, `mild steel products`) cluster onto `/products` as the MS commercial hub because no single MS product page should absorb them; the definition term `mild steel` stays on the info blog. `mild steel pipe` reassigned to the A53 ERW page (nearest existing pipe owner) since there is no MS-specific pipe page. Primary vs secondary preserved so "ms plate" (primary of the plate page) and "ms plate supplier" (secondary, same page) don't compete.

**2. Carbon Steel** — Spec grade families each own one page: A106 owns all `a106*` and `astm a106` variants; API 5L owns `api 5l*`; SA516 owns `sa516 grade 70*`; A53 owns all `erw*`. Generic `carbon steel pipe`/`carbon steel pipe supplier`/`seamless pipe supplier` cluster onto ONE new generic CS-pipe page rather than diluting the spec pages. `carbon steel seamless pipe (supplier)` and bare `seamless pipe`/`seamless steel pipe` are Product/Commercial secondaries on the A106 page (its exact grade), keeping the spec intent primary.

**3. Alloy Steel** — P11 and P22 own their standalone pages (all A335/seamless variants). The alloy hub owns `alloy steel pipe (supplier)` as primary, and absorbs `chrome moly*` plus ALL `p91*` terms as secondaries (P91 has no standalone; Expand action flagged). Definition `alloy steel` stays on the info blog.
