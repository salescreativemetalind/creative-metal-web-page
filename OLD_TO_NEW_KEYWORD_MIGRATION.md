## Action legend

- **REASSIGN** — page's old head-term ownership moved/broadened toward the new cluster.
- **SUPPORTING** — retained as-is; supports a cluster (informational/secondary/location) — no targeting edit.
- **CONSOLIDATE** — cannibalization cluster; single owner designated (own-on-hub); satellites keep distinct intent.
- **REVIEW** — flagged for a later, carefully-reviewed decision (indexation/consolidation/dead map entry). No edit now.
- **RETIRE** — old *targeting* retired (not the page); term no longer an intentional PRIMARY SEO target.
