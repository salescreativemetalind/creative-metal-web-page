## Flange Face Types

| Face Type | Abbreviation | Description | Used With |
|-----------|-------------|-------------|-----------|
| Raised Face | RF | 1.6mm raised (Cl 150/300), 6.4mm (Cl 600+) | Most common, spiral wound gasket |
| Flat Face | FF | Flush face, no raised area | Cast iron flanges, non-metallic |
| Ring Type Joint | RTJ | Grooved for metal ring gasket | Class 600+ high-pressure |
| Tongue & Groove | T&G | Male (tongue) mates with female (groove) | Self-aligning, critical sealing |
| Male & Female | M&F | Raised (male) fits into recessed (female) | Heat exchangers, special equipment |

## How to Use This Chart

**1. Identifying an Unknown Flange:**
Measure OD → find matching size in table. Count bolt holes and measure bolt circle to confirm class.

**2. Ordering Bolts:**
From chart: Number of bolts × bolt length (calculate from flange thickness + gasket + nut height).

**3. Gasket Ordering:**
Use RF diameter from chart as outer reference for gasket sizing.

**4. Checking Flange-to-Flange Compatibility:**
Both flanges must be same class, same size, and same face type to mate correctly.

## Frequently Asked Questions

**Q: What is the OD of a 4" Class 150 flange?**
A: 229 mm (approximately 9 inches). Bolt circle is 190.5 mm with 8 bolts of 5/8" size.

**Q: How many bolts does a 6" Class 300 flange have?**
A: 12 bolts of 3/4" size on a bolt circle of 269.9 mm.

**Q: Can Class 150 and Class 300 flanges bolt together?**
A: Generally NO — they have different bolt circles, bolt sizes, and number of bolts (except for some sizes where dimensions overlap). Always match class-to-class.

**Q: What is the difference between Class 150 and Class 300?**
A: Class 300 has thicker flange body, larger bolt circle, more/bigger bolts, and higher pressure rating. Class 300 handles approximately double the pressure of Class 150.
