## API 5L Applications

**Oil Transmission:**
Crude oil trunk pipelines (IOCL, BPCL, HPCL product pipelines). Grades X42-X60 PSL2 in 8" to 36" LSAW. Complete with 3LPE/FBE coating.

**Gas Transmission:**
Natural gas trunk lines (GAIL, GSPL pipelines). Higher grades X52-X70 PSL2 for high-pressure transmission. Supplementary requirements SR1, SR2 for fracture control.

**Sour Gas Pipelines:**
H₂S-containing gas lines (ONGC fields). PSL2 with NACE compliance (SR3 — HIC test, SR4 — SSC test). Hardness controlled ≤ 22 HRC.

**Water Pipelines:**
Municipal and industrial water transmission. Grade B or X42 PSL1. ERW or SSAW for large diameters. Cost-optimized.

**Process Piping:**
Within refineries and gas plants where API 5L is specified (flow lines, utility lines). Seamless for HP service.

**Q: What is the difference between API 5L and ASTM A106?**
A: Both are carbon steel pipe specs. API 5L is specifically for pipeline transport (oil, gas, water). ASTM A106 is for high-temperature process piping. API 5L has PSL levels and pipeline-specific requirements. A106 has temperature ratings. They can overlap for some applications.

**Q: Can API 5L be used for process piping?**
A: Yes, where the applicable code (ASME B31.3/B31.4) allows. API 5L is accepted for process piping with appropriate pressure-temperature ratings. Many refinery designs use API 5L for utility and transfer piping.
